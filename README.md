# Sistema Web para Gestión y Cotización de Carpintería 🪚

Plataforma web desarrollada para automatizar la cotización de muebles estandarizados, agendar visitas técnicas y gestionar el catálogo y los pedidos de un taller de carpintería. 

## 🚀 Características Principales

* **Cotizador Paramétrico:** Cálculo de precios al instante basado en dimensiones, tiempo de elaboración y distancia de entrega para muebles estandarizados.
* **Módulo de Citas:** Calendario interactivo con validación de horarios para visitas de toma de medidas.
* **Catálogo de Exhibición:** Visualización detallada de proyectos y muebles organizados por categorías fijas.
* **Panel de Administración:** Gestión de inventario base, revisión de croquis adjuntos y actualización manual del estado de los pedidos y fechas estimadas de término.
* **Seguridad:** Cifrado de contraseñas (bcrypt/Argon2) y bitácora de eventos para auditoría del sistema.

## 🛠️ Stack Tecnológico Sugerido

* **Frontend:** HTML5, CSS3, JavaScript (DOM, AJAX, jQuery).
* **Backend:** PHP.
* **Base de Datos:** MySQL / MariaDB.
* **Control de Versiones:** Git / GitHub.
